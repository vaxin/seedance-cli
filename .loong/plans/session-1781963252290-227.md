# Plan: extend 命令改用本地视频文件 + 自动裁剪

## Overview

将 `extend` 命令从「通过 task ID 获取视频 URL」改为「直接接受本地视频文件 + 自动裁剪过长视频」。裁剪逻辑：用 ffprobe 探测视频时长，若超过 `min(5, --duration)` 秒，用 ffmpeg 裁到该阈值（从末尾截取），再上传为 base64 data URI。

## Approach

1. **新增 `src/core/video.rs`**：封装视频时长探测（ffprobe）和裁剪（ffmpeg）逻辑。
2. **修改 `src/cli/extend.rs`**：将 positional `source: Vec<String>` task ID 参数替换为 `--source-video` / `-s` 命名参数，接受本地视频路径。在构建 content 时调用 `video::prepare_source_video()`（probe → trim if needed → upload as base64）。
3. **更新 `src/core/mod.rs`**：暴露新模块。
4. **更新测试**：适配新的 CLI 参数格式。
5. **更新 `SKILL.md`**：同步 extend 命令文档。

## Steps

### Step 1: 新增 `src/core/video.rs` — 视频探测与裁剪

- `probe_duration(path: &str) -> Result<f64>`：调用 `ffprobe` 获取视频时长（秒）
  - 命令：`ffprobe -v error -show_entries format=duration -of csv=p=0 <path>`
  - ffprobe 不可用时给出友好错误提示
- `trim_from_end(input: &str, output: &str, keep_secs: f64) -> Result<()>`：用 `ffmpeg` 从末尾截取 keep_secs 秒
  - 命令：`ffmpeg -y -sseof -{keep_secs} -i <input> -c copy <output>`
  - 不能用 `-c copy` 时回退到重新编码：`ffmpeg -y -i <input> -ss <start> -t <keep_secs> -c:v libx264 -preset fast -crf 23 -c:a aac <output>`
- `prepare_source_video(input: &str, max_duration: u8) -> Result<String>`：
  1. `probe_duration(input)` → 得到实际时长
  2. 若实际时长 ≤ max_duration，直接 `upload::resolve_file_ref(input)` 返回
  3. 若超过，用 `trim_from_end` 裁到 max_duration 秒，输出到临时文件，然后 `upload::resolve_file_ref` 上传临时文件
  4. 清理临时文件

### Step 2: 修改 `src/cli/extend.rs`

- `ExtendArgs` 结构体：
  - 删除：`#[arg(required = true, num_args = 1..=3)] pub source: Vec<String>`
  - 新增：`#[arg(short = 's', long = "source-video", required = true, num_args = 1..=3)] pub source_video: Vec<String>`
- `execute()` 函数：
  - 删除 `use super::common::{self, SubmitOpts}` 中对 `common::resolve_source_video_url` 的依赖
  - 将原来的：
    ```rust
    for source_id in &args.source {
        let video_url = common::resolve_source_video_url(&client, source_id).await?;
        content.push(ContentItem::VideoUrl {
            video_url: UrlRef { url: video_url },
            role: Some("reference_video".into()),
        });
    }
    ```
    替换为：
    ```rust
    let max_duration = args.duration.min(5);
    for src in &args.source_video {
        let url = video::prepare_source_video(src, max_duration)?;
        content.push(ContentItem::VideoUrl {
            video_url: UrlRef { url },
            role: Some("reference_video".into()),
        });
    }
    ```
  - 新增 `use crate::core::video;` 导入
